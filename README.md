# Arfan Shah School Management System — Mobile Test v1

Includes Chairman/Admin, Teacher and Parent dashboards, English/Urdu/Arabic
selector, Quran education section, sample students and school statistics.

This is a DEMO test build: data is in memory only. Real database, secure
authentication, permissions, fees, payment gateway, subscriptions and cloud
sync are planned for the next phase.

Phone-only build path: upload this project to a GitHub repository, then use the
included GitHub Actions workflow. It builds app-debug.apk and uploads it as an
Actions artifact.
